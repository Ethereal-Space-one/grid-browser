# Security policy

Grid Browser has no stable release yet. The WebKit probe and search prototype are experiments, not a browser recommended for daily use.

Please use GitHub's private vulnerability reporting for security issues. Do not post exploit details, credentials, private browsing content, or sensitive logs in a public issue. The repository maintainers will acknowledge the report and coordinate a fix and disclosure with the reporter.

Browser security fixes and Chromium upstream updates are release gates. A successful prototype or local build is not a security support commitment.
