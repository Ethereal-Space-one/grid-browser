# macOS 开发者预览与试用任务

日期：2026-11-04。范围：本机 Apple Silicon macOS 预览，不是正式公开发行版。

## 启动

在仓库原型目录运行 `npm run package:mac`，输出 `.local/release/Grid Preview.app` 及 `Grid-Preview-mac-arm64.zip`。本机可双击 app 启动；zip 可作为本地交付副本。应用采用本地 ad-hoc 签名并通过 codesign 校验，尚无 Developer ID 签名、公证或自动更新。其他机器下载后的 Gatekeeper 行为及独立安装仍待验证，不应关闭系统保护来绕过。

首次启动可以直接浏览网址。在首页“搜索服务设置”输入自己的 DeepSeek key，保存到本机。主进程使用 Electron safeStorage 的异步系统加密接口，磁盘只保存密文；输入框保存后清空。已有环境变量优先；测试报告和安装包不包含个人 key。删除或轮换 key 的完整设置界面尚待补充。

打包后的 MCP 配置使用 app 自带的 Electron/Node 运行时，附带 `ELECTRON_RUN_AS_NODE=1`；无需为 MCP 另装 Node。开发源码仍需要 Node。移动 app 后需要重新复制配置。

- 真实 Search：五种场景分别返回 10、10、10、10、9 条结果；关闭优化返回 10 条。只代表一次查询，不构成质量排名。
- 真实 Fetch：公开 Electron WebContentsView 文档返回 1436 字符；五种真实模型提取均非空。尚未做人工忠实度与相关性评价。

机器报告在 `.local/`，不进入仓库。真人对照结果必须另行记录，不用自动点击耗时冒充用户完成时间。

## 任务 A：搜索并按场景阅读（用户已选择先试）

1. 用自己真实想了解的问题，先关闭“按场景优化搜索”，查看前三条结果；记录是否可用。
2. 返回首页，保持同一个问题，选择一个合适场景并开启优化，再看前三条结果。
3. 打开其中一条的干净正文，点击按场景提取重点，选择一条重点在下方原文中找依据。Fetch 失败则尝试打开原页，也算需要记录的结果。
4. 在惯用浏览器用同一问题完成一次查找，比较实际花费的时间和注意力。

请反馈：问题和所选场景；前三条结果中可用的数量；一条重点能否找到原文依据；哪一步最困惑或等待最久。可以只给文字，不需要提供个人网页、密钥或完整浏览记录。

## 任务 B：连接与读取

在 Grid 打开公开文档，复制配置到惯用 AI 编程工具；请求读取当前页面，在 Grid 核对连接和范围后授权。随后撤销并再次请求读取。记录从开始到首次成功读取的实际步骤与时间，以及是否清楚发给了哪个客户端。

## 任务 C：提案、拒绝与接管

启动 `python3 scripts/serve-fixtures.py`，打开 `http://127.0.0.1:8765/actions.html`。让 AI 工具提出合成任务代号填写计划。先暂停，确认原页没变；恢复后取消，确认没有填写；重新提案再确认，检查内容正确且未提交。记录是否能说明谁、在哪页、填哪个字段、填什么，以及如何拒绝。不要使用真实工单或个人信息。

## 对照结果记录

模板：`docs/developer-trial.template.csv`。字段为任务、工具、场景、是否完成、秒数、步骤数、可用结果数、原文依据核对、接管是否成功、主观困扰及下次是否愿意使用。未收集的字段留空，不填推测值。用户结果文件放在 `.local/`，只在用户愿意公开时才整理入仓库。
