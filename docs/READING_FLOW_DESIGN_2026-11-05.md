# Grid 同窗阅读：动线、层级与功能核对

2026-11-05。以 PLAN.md 为主。用户反馈当前体验“不好用”，明确要求点击搜索结果看到真实网页、上方按需总结，并参考 Arc/Dia 的浏览器空间组织。最初交付为离线交互原型与接入规格。用户随后明确确认以此模板实现：现在已交付首个 Electron 版本，详见[首版实现与验证范围](./SMOKE_READING_FLOW_2026-11-05.md)。下文是完整交互目标与原型说明；图片、连续多轮、活动详情归并及部分次级菜单仍未全部迁移，不能将原型演示等同实际能力。

## 1. 本次决定

1. 点击结果标题直接打开真实网页，原页是默认主区。干净正文保留为次级阅读工具，A/B 不再是待选的默认动线。
2. 浏览器导航位置稳定。网页上方只有紧凑的「总结这页」、当前场景、轻量「问这页」和更多操作；不常驻研究工具栏。
3. 点击总结后在上方展开有高度上限的摘要；生成期间可以继续浏览。打开右侧追问后，上方摘要收起；不同时占用两块 AI 内容区。
4. 用户进一步确认地图悬浮在页面最下方：默认小浮钮，展开为贴底毛玻璃区域，节点紧凑、默认横向并可切纵向。最新的底部锚定替代自由拖动。标签仍在左侧可收起导航；地图不挤压网页。删除只移除该节点，后续分支接回上一级，支持撤销。
5. 页内问答和个人记录附着于对应访问/文档，地图提供进入它们的入口；不能为了减少 UI 而删掉已有问题、旧分支和判断版本。
6. 引用、比较、记录在需要时进入；设置、历史记录和 Agent 连接留在管理入口。Agent 执行中的暂停/接管是例外：必须始终可见。
7. 用户要求不同链式地图对应不同标签、可自行切换。**用户已确认的切换方案，首版已接入、实际体验待试用**：一枚「探索标签」对应一张地图，网页是其中的访问节点。左侧与底部共用当前探索，选择另一标签同时切换网页和地图；不让两个入口各选一张不同的图。

## 2. 从参考产品学到什么

- [Arc 官方介绍](https://arc.net/)及其官方 Split View 展示：侧面组织导航与打开的页面，网页占主要区域。Grid 采用“一个导航位、可隐藏”的原则，不照搬 Arc 的空间/收藏体系。
- [Dia 官方上手说明](https://www.diabrowser.com/download/thanks)：从正在浏览的页面发起 Chat，不必先换到另一个工具。Grid 采用与当前页邻接的辅助区域；总结的上方展开是本项目用户提出的设计。
- [Dia 更新日志](https://www.diabrowser.com/changelog/mac)：将侧栏/分屏切换时的稳定性作为体验细节持续优化。Grid 相应要求布局变化不重建网页、不丢滚动与输入。

这些是从官方说明和公开界面中提炼的布局原则，不是竞品的完整实机测试，也不证明 Grid 已取得相同效果。色调继续使用仓库的系统字体、浅深色中性色与五场景 token；第三方原页不被 Grid 换色。

## 3. 按点击递进的空间与按钮

| 当前状态 | 主动作与视觉权重 | 次级入口 | 点击后的空间变化 |
|---|---|---|---|
| 首页 | 「搜索」为实色按钮；输入是视觉中心 | 五场景为轻量选择，查询优化可关，服务设置为文字入口 | 提交进入结果页；选场景本身不联网 |
| 搜索结果 | 标题是最重要的可点击链接，不要求再找“打开”按钮 | 「概览结果」、查询/提供者说明、标准新标签操作 | 标题进入原页；概览只在结果页内展开 |
| 正常阅读 | 「总结这页」为小面积场景色入口，网页仍最突出 | 「问这页」为文字按钮；更多内有干净阅读/比较/记录 | 总结在上方展开；问答在侧面展开 |
| 总结加载 | 显示读取依据与状态；取消为中性按钮 | 可随时收起、继续滚动网页 | 生成结果只替换同一有界区域，不再次推动网页 |
| 总结就绪 | 两三句摘要，来源与生成范围可查 | 底部「继续问这页」；隐藏上方重复的同名入口 | 打开问答并收起总结 |
| 追问 | 面板内「发送」为唯一实色提交动作 | 原文依据、关闭、生成时取消 | 只更新本页会话；网页不换成回答页 |
| 来源对照 | 选够两份才启用「比较这两份」 | 改选来源、核对原文、记下判断 | 在辅助区中逐步展开，当前网页保留 |
| 我的记录 | 「保存新版本」为当前编辑的提交动作 | 附引文、旧版本、待核内容 | 保存后保留旧版本，不覆盖 AI 与个人文字的区别 |
| 探索切换（原型方案） | 左侧列出探索标签，选中项明确标记「当前」 | 底部地图名称与箭头展开同一列表；收起后保留箭头入口 | 列表在底部区域暂时替代地图，选定后回到该链上次停留页及对应地图 |
| 底部地图 | 当前节点通过底色与“当前”文字标记 | 横竖切换、定位、撤销；当前节点的继续/移除；关联活动 | 小浮钮按需展开贴底毛玻璃；不改网页尺寸；选点返回，从该点继续新增分支 |
| 管理区 | 当前任务的动作才有实色强调 | 设置、连接、回执、删除 | 不与阅读主流程争抢常驻位置 |
| Agent 执行 | 可信的暂停/接管控制持续可见 | 展开详情查看范围、目标、输入与影响 | 收起面板不能隐藏控制；接管后旧动作不得继续 |

状态规则：悬停只改变背景；键盘焦点可见；按下有轻微位置反馈；不可用按钮保留原因；加载有可取消状态；失败在原位置解释下一步；成功不自动跳走。默认、hover、focus、active、disabled、loading、error、success 都有对应实际交互。减少动效设置关闭转场。

## 4. 模拟用户动线

### A. 只想看网页

首页选择「专业」→输入问题→搜索→点结果标题→阅读原页→点击页内链接→后退。

不用点总结，不需要理解地图、Agent 或记录。网址输入仍走直达。无 key 只影响需要服务的检索/模型功能，不能阻断普通浏览。

### B. 想看懂这页

原页→「总结这页」→两三句摘要→「继续问这页」→输入问题→查看依据→回到原文位置。

展开/收起不清空网页字段和位置。公开 Fetch 无法取得正文时明确说明，不能拿搜索摘要冒充网页总结。当前生产实现读的是公开 Fetch；登录后内容、动态内容和屏幕实际所见并未自动进入模型。真正读取当前会话内容须另做明确范围、字段过滤和授权设计。

### C. 探索后回来

网站节点缩至 164px 宽，分别保留两行标题和两行内容摘录，过长省略；完整文字留在可访问名称/描述与悬停/焦点提示中。短内容不补写凑行。已有图片缩为顶行 44×26px 小预览，标题和摘录仍占整行；无图或图片失败时保持纯文字，图片点击等同点标题。左侧标签保留两行标题，搜索结果内容也预留两行。摘录取已有来源内容，不因展开地图发起提取或模型请求。离线示例摘录与图片来自本原型文章，不代表已经实现真实网站取图、截图或图片缓存。

结果→原页 A→追问并留下草稿→地图返回结果→原页 B→地图选 A→原问题/回答/草稿仍在→后退再前进仍沿 A 分支。

地图保留 B；点击 A 下的问答/记录入口回到相应辅助视图。地图默认突出真实访问，活动作为关联详情；展开工具和生成进度不形成假访问。正式迁移须保留旧版独立问答/对照/判断节点，不能删除历史来简化地图。

展开页面底部居中的「地图 · 当前名称」→点旧节点回到该页→「从此处继续」→输入新问题或网址→提交后才新增分支，原有后续仍在。地图只显示当前任务，固定在内容区底部；默认横向，可切换纵向，图内滚动，「定位当前」找回当前位置。顶栏放当前探索名称/切换、方向/定位/撤销，底栏放当前节点的继续/移除。地图不遮挡地址栏、总结工具条或 Agent 控制条。玻璃背景配合更实的节点底色保证文字清晰；减少透明度、增强对比或不支持模糊时回退实色。打开问答时收起地图；窄窗主动打开地图会收起辅助面板，草稿保留。

「移除此节点」只改变地图关系：直接子节点按原顺序接回父节点，删除根时子节点成为同一任务内的多个起点。删除当前节点不关闭或刷新网页，滚动与输入保持；该页仍可从「当前链的网页」访问，地图显示“已移除”。后退跳过已移除节点；后续继续操作从最近保留上级续接，空图中则建立新起点。

撤销按本任务的删除顺序逆序恢复节点与连接；删除后新增的分支和当前选定前进方向不能被整树回滚覆盖。取消“继续”不产生节点，中文输入法候选确认不提交。移除是整理地图，不是隐私擦除或撤销网站动作：关联活动留在打开页面及可撤销内容中；清除任务及关联内容仍走本地记录的整条删除，并同时清理撤销历史，防止复活。正式持久化、撤销期限与存储预算仍须另行实现与验证。

### C2. 在两条探索之间切换（原型方案）

「减少浏览干扰」链停在原页 A→点击左侧「记录阅读想法」标签→网页与底部地图共同切到第二条链的上次停留页→点击底部当前探索名称旁的箭头→选回第一条→回到原页 A 的阅读位置。

- **两个入口，一个当前探索**：侧栏展开时直接点标签；专注阅读、侧栏隐藏时点地图名称或收起浮钮旁的箭头。底部列表暂时替代图与编辑控件，避免同时出现两组操作；切换后恢复原来的展开/收起状态。Esc 取消，不导航，焦点回到入口。
- **选择前能认出内容**：名称取首次查询或起始网页标题，不随每次导航改名；未开始时显示「新探索」。名称最多两行，下一行显示节点数和上次停留页；当前项有文字标记。相同名称仍是独立身份，保留可辨序号；不能按 URL 合并。列表多时内部滚动，保留「新建探索」入口。悬停不切换页面。
- **继续与新建有区别**：「从此处继续」、同链节点和普通链接留在当前链；「新建探索」及显式「新标签打开」建立新链。换标签不会创建节点、重新检索或改变旧分支；链内前进/后退仍按原先选定方向。
- **回来后能接着做**：保存各链最后访问、阅读位置、问题草稿、未提交的继续草稿、地图方向和比较选择。取消旧的未完成生成，旧页面或授权不能误作用到新链。删除单节点不删除标签；整链删除才清除对应标签、内容及撤销记录。

原型默认提供两条合成链供比较；「演示状态 → 重新开始」返回单个首页，「查看多标签示例」重建示例。这只是当前打开期间的内存演示；不表示正式应用已支持该标签层级、真实网站实例无损切换或跨重启恢复。新标签与来源链的跨链溯源、重命名/整理方式不在本轮实现范围。

### D. 按需研究

原页更多→比较来源→主动选两份→比较→核对依据→我的记录→保存新版本→本地记录→恢复。

比较在选择完成前不能发送，不能因为“打开过”就读取全部标签。个人记录不默认发给模型。正式应用继续固定来源版本、逐字引文与时间，并区分不足、缺失和错误；原型仅展示示例结构，未实现语义质量。

### E. 失败、打断与控制

- 提取失败：原页留在原处，显示失败及「重新获取」；不生成猜测答案。
- 取消生成：保留问题草稿；迟到结果不覆盖另一页或取消状态。
- 切换页面：上下文按文档分开，旧请求不能覆盖新页。
- Agent：连接→当前文档读取授权→单独的填写提案→确认→过程→暂停/接管。读取同意不包含写入同意。
- 网页失效：显示恢复原因，由用户重新打开；POST/写操作不随导航重放。此边界由现有生产检查覆盖，原型不模拟网络重放。

## 5. 功能与优化逐项核对

| 已约定内容 | 新界面去向 | 本轮原型与后续边界 |
|---|---|---|
| 专业、学习、生活、娱乐、灵感 | 首页五场景；网页工具条显示该页场景 | 切色与短反馈可点；真实策略沿用现有适配器并重新验内容质量 |
| 场景参与搜索和正文提取 | 查询优化可关；总结/提问继承页面场景 | 演示不同视角，不调用 API；真实查询必须由 Host 返回，不由 UI 猜造 |
| 无画像、无参与度重排、无广告位 | 结果及可展开查询/来源说明 | 原型明确为录制示例；正式透明规则保留 |
| 结果先可用，概览按需 | 结果标题直接点击；概览为次级按钮 | 原型可点；生产标题直达与真实检索需接入复验 |
| 网址直达不经模型 | 固定地址栏 | 原型只识别示例网址；任意网络浏览仍由现有 Electron Host 实现 |
| 真实原页默认、正常页内点击 | 最大的主阅读区域 | 原型为本地合成网页，不冒充线上页面 |
| 干净正文与 Fetch 失败回退 | 更多→干净阅读；原页一直保留 | 保留能力，不再抢占默认点击；缺失时不自动切成模型回答 |
| 当前页两三句总结 | 上方按需展开，加载/失败/成功同区 | 可演示；生产网页总结、来源版本和缓存归属待接入 |
| 问这页与连续追问 | 右侧，同页保持问答和输入 | 连续多轮是新目标；生产当前仍为独立问题，原型不代表已打通上下文 |
| 两来源比较、版本及引用 | 更多→比较→选两份→结果与依据 | 原型演示选源与对照布局；正式复用原有受限来源契约 |
| 我的判断、待核事项、不可变版本 | 更多→我的记录；地图的关联活动 | 版本在内存演示；生产保留独立字段，不能用原型单文本框降级现有契约 |
| 链式地图、点击返回、前后切换、保留分支 | 网页底部毛玻璃地图，紧凑节点、横竖切换 | 原型可点；生产需可信原生浮层与 Host 导航接入 |
| 节点删除、撤销、从节点继续 | 地图当前节点下方，点选后操作 | 子分支接回上一级；撤销保留后增分支；不关闭当前页，不是隐私擦除 |
| 不同地图对应不同标签、自由切换 | 左侧探索标签＋底部名称/箭头列表；当前链网页为下一级 | 用户已确认模板，首版原生切换已接入；保留窗口/标签/后台任务及已有恢复，实际体验仍待试用 |
| 位置、网页输入、提问草稿 | 页面继续存在；数据绑定对应访问 | 原型验证展开/关闭与切换；实际原生网页须单独测 |
| 本地保存、恢复、删除、非持久任务 | 管理入口→本地记录 | 原型仅内存；生产已有跨进程持久化，迁移不能回退成内存保存 |
| 隐私与原始正文边界 | 保存说明及数据管理 | 不存密钥/授权/表单值；不默认全量保存正文；非持久任务不是完整隐私浏览 |
| MCP 连接、客户端范围、撤销、读取回执 | 管理入口→Agent→连接/回执 | 原型解释入口，不生成凭据；复用真实桥接，保留配置复制和元数据导出 |
| Agent 预览、确认、暂停、接管 | 辅助面板＋执行时可信状态条 | 控制为模拟，不填写网页；现有固定字段实验不扩大成任意网站 Agent |
| 导航撤权、未知动作结果、不重放 POST | Host 规则，前台只呈现准确状态 | 原型不证明安全；正式接入必须回归所有现有用例 |
| 加载、取消、空结果、失败重试 | 发生处局部反馈 | 原型可从外部「演示状态」触发；不是产品常驻按钮 |
| 苹果式克制色调、字体、浅深色 | 共享 tokens；网页自己的颜色独立 | 原型复用仓库 tokens，不另造一套产品主题 |
| 层级、低干扰动效、窄窗、键盘/中文输入 | 标签导航、默认收起的地图、一个辅助位；减少动效、焦点返回 | 有自动布局/焦点/输入法事件检查；完整读屏与真人体验仍待测 |
| 下载、权限、登录、媒体、PDF、迁移等 | 保留浏览器基建路线图 | 本轮不做按钮占位伪装支持，不从计划删除 |
| 第二检索源、安全更新、签名公证、跨机安装 | 后续工程与发布门槛 | 不被视觉重设计替代 |
| 可选证据与 .lattice | 需要核对/分享时的高级能力 | 继续后置，不在主流程增加证据关卡 |

## 6. 接入正式应用的分步出口

当前进展：原生内容布局/标题直达、公开正文总结、同窗独立问答、可信底部地图与探索切换已接入；单点移除及其存储投影、运行期间撤销/续接也已实现。以下出口仍按实际证据分别验收，尤其不把锁屏环境下的自动布局检查算作完整原生合成、隐藏/恢复或用户体验通过。

1. **原型与动线复核（本轮）**：读网页、总结、追问、地图分支与次级工具都可点；明确样例内容与全部未实现边界。自动模拟不代替用户认可。
2. **原生布局与入口**：复用现有 BrowserTab/Host，把真实结果标题接导航。布局从仅顶部 chrome 高度升级为受控网页矩形 x/y/width/height，校验窗口/标签/布局票据/缩放；布局本身不刷新页面、不撤销当前文档授权。左导航和右辅助区都不能被 WebContentsView 盖住。底部地图另验浏览器拥有的可信原生浮层：不能把 DOM z-index 当成可覆盖原生网页的证据，不将地图脚本注入网站。验证视图层级、透明区域点击、焦点、缩放、底部锚定、全屏与后台隐藏；浮层限于内容区，不能覆盖接管或系统授权。真实网页是否参与毛玻璃合成须实测，不以本原型 CSS 模糊代替；不可用时采用实色，不额外抓取或截图来模拟玻璃。
3. **同页理解**：将总结、问答草稿与会话绑定 window/tab/visit/document/sourceVersion/scene；公开 Fetch 与当前会话内容明确区分。先保持现有读取边界；多轮携带哪些内容、长度与取消策略需以小切片实现并测质量。
4. **导航与持久化兼容**：地图从 Host 快照渲染，页内活动不是第二套网页历史。保留旧版独立问答/比较/判断节点与记录；先做向前兼容投影，不破坏已保存文件。新访问、后退、选分支与多标签身份共用既有导航入口。探索标签方案需以稳定链 ID 和最后访问 ID 接入同一受控激活入口，原生页面与地图当前状态共同更新，旧请求/授权不能串链；既有一标签多路径等数据须兼容投影，不能直接删除或按标题合并。单节点移除/撤销由 Host 原子处理父子关系、选定后续、当前文档与活动引用；任务 ID 不因根节点移除改变。升级保存版本并明确撤销数据寿命；整条删除清理撤销并拦截迟到保存。
5. **其余功能归位与回归**：按上表逐项迁移入口；比较/判断的固定来源、草稿和版本、存储删除栅栏、MCP/动作权限均复验。活跃 Agent 的控制条不能随侧栏收起消失。
6. **新包与用户试用**：真实 Search/Fetch/Model、真实页面滚动/表单/SPA、跨正常退出恢复、键盘与读屏完成后再打包。用户按 A/B/C 三条路径评价；未通过前不宣布好用，不用自动检查数量作体验完成度。
