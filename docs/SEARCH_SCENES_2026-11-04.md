# 五种显式搜索场景

日期：2026-11-04。用户确认采用：专业、学习、生活、娱乐、灵感。此选择只表达用户本次意图；不读取浏览历史、不建立画像、不增加推荐流。选择保存在当前应用进程内，重启恢复专业场景。

## 行为

- 首页搜索位置提供五项单选，支持原生键盘操作；配色分别为青、紫、暖金、粉、绿。切换为 220ms 的轻微位移/淡入和颜色过渡，遵守系统减少动态效果偏好。
- 默认开启场景优化。Search 的 `query` 附加场景检索词，`ori_question` 明确场景与原始问题；结果页展示使用的场景及实际查询，保留提供者顺序。关闭优化使用原始查询。网址直达不经改写。
- 专业检索偏向官方资料/原始来源；学习偏向教程/概念；生活偏向指南/注意事项；娱乐偏向作品/体验/评价；灵感偏向创意案例/不同视角。它们是可检查的确定性查询策略，并非已验证的质量改进。
- Unicode 查询超过提供者 128 字符上限时明确提示缩短或关闭优化，不静默截断问题或搜索运算符。
- 干净正文仍先按 URL 调用 Fetch。用户点击“按某场景提取重点”后，才将当前已抓取正文前 16000 Unicode 字符、查询和场景发给 DeepSeek `deepseek-flash`，使用 Chat Completions 的系统提示词指导提取。额外模型调用在按钮旁说明；不自动提交私人会话页面。
- 提取结果标记为 AI 生成、未经核对，必要时标记仅基于正文前段；原文始终完整保留。模型失败可以继续读原文或打开原页。模型结果作为纯文本呈现。

官方 [Search & Fetch 文档](https://api-docs.deepseek.com/guides/search/)列明 Search 的 `query`、`ori_question` 等字段；未知字段会被忽略，Fetch 只支持 URL。因此没有向这两个接口伪造 `prompt` 参数。按场景提取通过单独的 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 调用完成；模型版本及 API 变化需要持续跟进。
