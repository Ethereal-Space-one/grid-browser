# WebKit 对照样机首次实测

日期：2026-10-30。设备：本机 Apple Silicon，macOS/Xcode SDK 27.0，Swift 6.4。对象：当时名为 `LatticeBrowserProbe` 的 WebKit 对照样机，现已更名 `GridBrowserProbe`。以下是开发者冒烟检查，不是用户研究，也不能代替 G1 Chromium 对照。

| 检查 | 观察 | 结果 |
|---|---|---|
| 构建与纯逻辑测试 | SwiftPM 编译，Omnibox 网址、查询、非法 scheme 与编码 4 项测试 | 通过 |
| 网址直达 | 输入 `https://example.org`，真实网页加载，地址栏保留 URL | 通过 |
| 查询回退 | 输入“开源浏览器”，打开 Bing 搜索页 | 通过；Lattice 搜索页未实现 |
| 前进后退 | 外部搜索后返回原页 | 通过 |
| 新标签与切换 | 新建标签；本地页面 `target=_blank` 打开第二页；切回后原表单及 iframe 状态仍在 | 通过 |
| 本地动态表单 | 提交 `T0-01`，页面显示“已记录：T0-01” | 通过 |
| 本地 iframe | 提交 `T0-02`，框架显示“框架已确认：T0-02” | 通过 |
| 本地下载 | 点击 `sample.txt`，系统保存面板出现，保存后内容与夹具相同 | 通过；测试文件已移出 Downloads |

检查中修复了首页地址、标题状态与下载处理。尚未检查登录、上传、PDF/视频、输入法、屏幕阅读器、权限提示、崩溃恢复、跨平台、安全更新、搜索质量或 AI。因此现阶段只证明了**一个能浏览真实网页的 WebKit 对照切片**。
