# 受限表单填写原型实测

日期：2026-11-03，macOS / Electron 45.2.1。仅在本机合成页面 `/actions.html` 的 `input[name=task]` 上验证，不代表任意网站或正式内核安全验证。

运行夹具服务器 `python3 scripts/serve-fixtures.py`，启动 Grid 后打开 `http://127.0.0.1:8765/actions.html`，展开 Agent 面板，输入合成任务代号并点击“预览填写”。预览显示来源、固定字段名与拟填写内容。用户可以暂停、恢复、确认或接管取消；恢复后仍需确认。填写不会触发 input/change 事件，也不点击提交，因此尚不支持依赖这些事件的框架表单。

`npm run test:e2e:actions` 使用临时资料档及本地服务器，真实界面预览按钮与主进程调用交叉验证：

- 预览不修改字段。
- 暂停时确认被拒绝，恢复不会自动执行。
- 确认后字段内容正确；未提交；重复确认被拒绝。
- 接管取消后旧预览失效。
- 人工改值保留，旧预览拒绝覆盖。
- 替换 DOM 字段后旧预览拒绝执行。
- 导航后旧预览失效。
- 其他本地路径不能创建填写预览。

上述八组检查通过，退出码 0。已有八项本地检查及 Electron/MCP 只读回归通过。预览截图保存在被忽略的 `.local/actions-preview.png`。

实现以主进程文档身份、随机预览 ID、隔离世界中字段对象身份及预览时的值作检查。不是网页可信性证明：任何本地服务均可提供同路径页面，页面仍可观察字段变化，故只应用合成数据。暂停只控制待确认步骤；单次同步赋值不能中断或回滚。执行期间接管仅使回执标记需人工核对，不承诺阻止已排队的赋值。

后续同日扩展：外部 MCP 客户端可调用 `grid_form_propose({value})` 提出计划及 `grid_form_status` 查询自己的状态。需先获得当前文档读取授权；该授权仅允许创建提案，填写仍需用户在 Grid 中单独确认，没有 MCP 确认、执行或脚本入口。提案显示客户端自报名称，不能替换已有待处理预览。断开、撤销、导航使未执行计划取消；授权过期时确认也被拒绝。

官方 SDK 客户端经过真实 stdio 子进程验证：未授权提案拒绝；提案不修改字段；拒绝覆盖待处理预览及混入 confirm 参数；用户确认后填写；查询返回完成状态；撤销与断开后不能确认；JSON 导出的 `formActions` 状态元数据不含填写值。加上原八组，共十二组端到端检查通过，退出码 0。十项本地检查（新增授权到期阻断与预览失败清理）与 MCP 读取回归也通过。该 SDK 测试本身不调用模型。同日随后完成 Codex CLI / Claude Code 的真实模型提案验证，首次 Codex 超时与回退延迟均保留，详见[立项目标与体验复核](./UX_HOST_FORMS_2026-11-03.md)。
