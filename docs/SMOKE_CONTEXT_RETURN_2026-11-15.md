# 网站引文的上下文返回与请求失败出口（本地源码）

基线：公开提交 `ba38fd747e2566441db86685b53dd776586e8cb9`。本次只在本地修改和验证，没有推送、发布或打包。

## 已实现

- 从「我的判断」的某条引文主动打开网站原页后，原有引文提示中增加「返回判断」。返回的是打开时同一节点、同一判断记录与修订，不是最新版本、来源问答或最后一次搜索。
- 保留原有草稿/只读版本、引用选择与阅读位置。返回不调用 Fetch、模型、Agent，不重新加载网站，也不新增判断版本。普通后退/前进的分支语义保持不变。
- 上下文保留在原有一次性定位租约中，仍受原有 owner、entry、document、WebContents、主框架、native visit、精确 URL 绑定。切标签/窗口、失焦、导航、刷新、关闭提示或文档失效会撤销；回到相同 URL 不会复活租约。
- 只有 Host 可以解析返回目标。IPC 只接收定位提示 ID 和当前 owner/entry；渲染器不能提交目标判断节点、地址或版本。Host 在动作前重新验证租约与原判断记录，来源节点已移除、内容已释放、修订不匹配时不跳转，也不回退到其他版本。
- 定位成功、重复、缺失、不支持和不确定结果都允许返回仍有效的判断；没有自动重试。定位期间返回会使晚到的 prepare 失效，不再发送滚动。
- 没有服务密钥时，在失败信息旁提供「设置本次搜索服务」及普通后退。设置入口只打开配置，不填入密钥、不启用服务、不重试请求、不进入 Agent。
- Fetch 失败时，提供「打开这次请求的网站原页」及普通后退。该地址只取自当前失败节点，核对 kind、status、runId 与 issue ID，不使用仍显示的旧 reading.url 或 state.value。界面明确现有正文是上一步，而非失败地址的新正文。

## 范围限制

- 「返回判断」只针对通过现有判断引文入口打开的网站。对照页普通「打开网站原页」没有这一租约，不借用判断能力或伪造引文定位；本轮保持普通后退。对照专属返回需要另设 Host 派生的精确来源/对照记录能力，再单独验证。
- 本轮不新增网站能力，不改变登录、表单、页面读取授权、任务持久化或原有一次性引文定位限制。上下文能力不会写入任务文件、MCP 回执或网站脚本。
- 本轮没有启动 GUI、使用真实 provider、调用模型、发布代码或执行原生布局验收。DOM 测试的可见性、焦点与布局为合成环境，不代表原生焦点或屏幕阅读器验收。

## 验证

在 `prototypes/electron-m0` 执行：

```sh
npm ci
npm run test:quote:setup
npm run test:context-return
npm run test:p0:ux
npm run test:quote:dom
npm test
```

实际本机结果：

- `npm run build`：通过。
- `npm run test:context-return`：32/32。生产用例、生产 Host 方法及编译后生产 DOM；合成服务与 IPC。
- `npm run test:p0:ux`：2/2。
- `npm run test:quote:dom`：快照匹配 31/31；locator UI DOM 检查通过；网站 DOM 安全边界 42/42。
- 不需要套接字的全部 Node 用例：113/113。
- `npm test` 的本地 MCP 套接字用例受执行环境的 Unix socket `listen EPERM` 限制，不能视为完整通过；其余用例通过。未把这些失败修改为跳过。
- `git diff --check`：通过。
