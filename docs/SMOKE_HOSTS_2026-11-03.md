# 真实编程工具接入实测

日期：2026-11-03。macOS，本机 Electron 45.2.1、Node.js 26.12.1、codex-cli 0.163.0、Claude Code 2.1.317。范围是 CLI 模型调用与 Grid 只读桥接；不包含 Codex 桌面应用或 IDE 界面接入验收。

## 实际链路

`npm run test:e2e:hosts` 启动独立临时 Grid 资料档、本地 HTTP 合成网页和真实 CLI 子进程。两个宿主分别使用独立连接及随机验证码。验证码只在页面中，启动提示不含答案。

1. 从产品复制入口取得本机 stdio 配置，传给真实宿主；不修改用户全局配置。
2. 模型调用连接状态、页面摘要，首次摘要读取必须被 Grid 拒绝。
3. 测试脚本核对当前地址是本次本地测试页后，在 Grid 界面自动点击授权。
4. 模型再次读取，并在最终回答中返回正确随机验证码。
5. 用当前连接的 Grid 回执交叉核对读取成功；检查输出未包含输入、密码或可编辑区域的测试值。退出后连接清除。

两个宿主均通过上述流程，退出码为 0。普通 8 项本地检查与 Electron/SDK MCP 回归也通过，后者补充检查 JSON 与 Codex TOML 的复制入口。

自动化授权并不等于人类完成授权测试；无字段值泄漏也只针对本次夹具，不是任意网站敏感信息防护证明。脚本只把合成网页文字交给客户端及其模型服务，不调用 DeepSeek。报告只保存检查结果和耗时，不保留原始 CLI 输出、验证码、页面正文、配置或密钥。

## 配置步骤

先在原型目录执行 `npm start`，打开要读取的页面。以下为手动操作流程说明，未招募首次使用者测量步骤数或完成时间。

### Codex CLI

1. Grid → Agent，选择 **Codex TOML**，复制配置。
2. 将复制的 `[mcp_servers.grid]` 段合并到自己的 Codex `config.toml`；如果已有同名段，替换该段，保留其他配置。
3. 启动新 Codex 会话，请它调用 `grid_connection_status`。
4. 在 Grid 检查当前页及连接请求，点击 **允许读取当前页**。
5. 请 Codex 调用 `grid_page_snapshot`，随后可在 Grid 撤销。

格式依据 [Codex 官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。自动测试使用本次进程的配置覆盖及临时工作目录，保留现有登录态，不写全局 MCP 配置。

### Claude Code

1. Grid → Agent，选择 **Claude Code / 通用 JSON**，复制配置。
2. 将 JSON 保存到本地私有文件，例如原型目录的 `.local/grid.mcp.json`。
3. 执行 `claude --strict-mcp-config --mcp-config .local/grid.mcp.json`，请它调用 `grid_connection_status`。
4. 在 Grid 检查页面及请求，点击 **允许读取当前页**。
5. 请 Claude Code 调用 `grid_page_snapshot`，随后可在 Grid 撤销。

格式及单次会话参数依据 [Claude Code 官方 MCP 文档](https://code.claude.com/docs/en/mcp)及本机 CLI 帮助。自动测试关闭内置工具，只允许两个 Grid 只读工具，使用非持久会话。

两种配置都包含本机绝对路径，只用于当前机器；移动项目或更换浏览器资料档后应重新复制。不要提交配置或本机连接描述文件。运行真实宿主需要该宿主自己的登录或模型配置，Grid 的 DeepSeek key 不替代它。
