# 第 6 步：完整任务精修、自动验证与试用交接

日期：2026-11-05。依据：[主计划](../PLAN.md)、[六步实施计划](./PATH_MAP_IMPLEMENTATION_2026-11-04.md)。本轮完成实现、自动检查和本机试用包；用户明确接手真人试用，内容质量和实际收益保留待验收。

## 用户可见的改动

- 搜索来源、排序与实际查询收进一处可展开说明。短总结默认紧凑；明确点击才展开，等待与回答完成沿用同一高度，避免异步结果再次推动来源列表。没有增加自动模型调用。
- 标签栏用“记录”区分保存状态与当前“地图”。本地记录以当前查询为标题，附当前步骤和时间；保存范围及容量按需展开，保留本机未单独加密、正文不保存和非持久任务共用登录状态的说明。
- 修复记录列表重绘遗漏当前路径 ID 的问题：仅切换任务、目录条目未变化时，“当前路径”仍正确迁移；删除后的标题能获得焦点。查询标题截断按 Unicode 字符处理，不截断代理对。
- 沿用系统字体、现有中性色、浅深色和五场景 tokens；没有更换页面结构或引入 UI 依赖。判断、问答和对照仍按点击分别进入，不成为搜索页常驻面板。
