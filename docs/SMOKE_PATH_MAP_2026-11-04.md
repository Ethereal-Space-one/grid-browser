# 链式地图第 3 步：路径栏、分支选择与网页布局

日期：2026-11-04。范围：[六步计划第 3 步](./PATH_MAP_IMPLEMENTATION_2026-11-04.md#第-3-步在真实应用接入路径栏和地图)。状态：**正式应用中的运行期间路径栏/地图已本机验证；理解页面、任务落盘与跨重启保存未实现。**

## 本轮交付与范围检查

实施前回查 PLAN.md 的立项目标与 §3.8、技术计划 §2.3.1，以及第 3 步的逐项出口。保留此前未提交工作，并保存本步前的工作区快照；没有更换框架、内核、字体或配色，也没有增加模型服务或数据外发。

- 新标签首页没有历史时不显示路径栏；开始探索后默认显示一行路径，当前节点有文字标记，选定后续以不同边框和文字区分。“地图”按需展开，显示真实父子关系及其他分支，不显示建议或尚未执行的计划。
- 搜索、正文和原页节点可点击返回；场景、已有内容、草稿与位置仍由既有宿主恢复。选择旧分支会改变之后的前进方向，其他分支保留；地图开关不建点，不重新请求 Search/Fetch/模型，也不重新加载当前网页。
- 节点带步骤序号、名称、来源、场景与时间，帮助区分重复访问。加载、失败、取消、内容释放及未记录续页有文字状态；不把“访问过”标成“已核实”或“已保存到磁盘”。
- 使用原生按钮、导航区域和嵌套列表，不冒用需要完整树控件键盘语义的 ARIA tree。展开入口有 aria-expanded/aria-controls，当前步骤有 aria-current。Tab 和 Enter 可用；方向键/Home/End 只移动节点焦点，Enter 才导航；Esc 收起并回到入口。紧凑路径跳转后焦点进入内容标题，真实原页则保留合理的路径入口焦点。
- 长路径使用内部滚动，深层缩进有上限，并显示父步骤引用；全部记录仍在语义列表内。缩放或宽度变化后校正当前节点位置，既不删节点，也不改变前进方向。

新增组件为 `src/renderer/path-map.ts` 与 `path-map.css`，沿用已有 tokens。它只呈现宿主快照，不另建导航树；地图开关是每标签的运行期间界面状态。生产界面没有新增问答、来源对照、判断或保存按钮，这些仍属第 4、5 步。

## 宿主布局与权限边界

可信 UI 观测实际控制区高度，连同当前标签和布局票据报告视口尺寸。Host 校验来源、归属、票据、有限数值与当前视口，按 UI zoom 转换为原生视图坐标；旧标签、旧票据、越界或伪造视口不能移动网页。重新加载 UI、切标签、改变窗口/面板或 UI zoom 会更新布局票据。

布局尚未确认时，网页暂不占用控制区；确认后按实际高度放置 WebContentsView。地图和 Agent 都有自己的滚动区域，小窗口保留可达的地图节点。内容区高度与同一份测量保持一致，避免 CSS 图层看似盖住了原生网页而点击仍落到网页。

地图展开/收起仅改变布局，当前文档身份和原有授权保留；调整过程中实际 MCP 读取会等待布局就绪，不能把布局短暂不可读当成文档已离开。跳到别的文档、切标签/窗口、隐藏/最小化等既有撤权规则保持。恢复旧节点不复活旧授权或动作；第 2 步的失效网页及 POST 不重发边界继续通过。

本轮核对了 [WAI Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)、[WAI Breadcrumb](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/) 和 [Electron View](https://www.electronjs.org/docs/latest/api/view)，并以安装的 Electron 45 类型及真实窗口验证实现。借鉴的是展开状态、当前位置语义和真实视图边界；分支地图的视觉及导航选择属于 Grid 设计，不据此宣称获得官方认证。
