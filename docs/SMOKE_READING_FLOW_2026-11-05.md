# 同窗阅读首版：原型迁移与验证

2026-11-05。用户确认以 `grid-reading-flow.html` 为交互模板，实现一版可运行应用，并允许优化视觉。本文记录 Electron 当前源码与本机预览；不是正式发布、真人体验通过或整个浏览器计划完成。

## 已接入的动线

- 首页五场景与现有搜索服务保留；结果标题直接打开真实原生网页。网址直达不经过模型。
- 网页上方按需「总结这页」；固定高度的内容区容纳加载、失败和结果，生成结束不再推动原页。关闭摘要不刷新网站。按需「问这页」在右侧展开，收起上方摘要，保留原页实例、滚动和输入；页内链接导航会退出旧页的问答区域。
- 左侧为探索标签和本链网页，底部名称/箭头切换同一组探索。名称取起始查询或网页，不跟随每次点击变化。切换共同恢复该链内容与地图，已有问题草稿、分支继续草稿、地图方向按链隔离。
- 地图在内容区底部浮动；横竖切换、定位当前、收起，不挤压网页，不遮住浏览器/Agent 控制。节点宽 164px，标题和摘录分别预留两行，正文来自已有结果摘要，不额外提取或编写补足。
- 单点移除只改变可见关系，子分支接回保留的上级，当前网页仍保持打开。撤销保留删除后新建的分支。续接先开输入，再提交新分支；取消、排版切换、中文候选确认都不提交。
- 来源对照、个人判断版本、本地记录及 MCP/受限填写保留原契约。问答、干净阅读、对照和判断在有对应存活网页时使用侧面区域；没有可恢复原页时保留独立内容与明确恢复入口。

## UI 与宿主实现

沿用 Grid 的系统字体、场景色和浅深色 tokens，降低结果列表装饰，按主操作/次级入口组织按钮。左侧导航可收起，窄窗第一次点击即可展开；窄窗追问时主动开侧栏会回到同一网页，保留草稿。地图支持 Tab、方向键/Home/End 移动焦点、Enter 访问与 Esc 关闭；方向键本身不导航。减少动效、高对比和减少透明度有样式回退，完整读屏仍待人工检查。

地图是独立的可信本地 `WebContentsView`，通过单独 preload 和受限 IPC 控制，网站无法获得其桥接。Host 校验窗口、标签、当前节点和布局票据；叠放范围取实测 chrome、侧栏、辅助区及缩放，不能靠网页 DOM 的 z-index 覆盖原生网站。

自动检查发现并修正了两项实际布局问题：搜索概览完成后状态条撤下导致结果跳动；macOS 原生地图外框缩小但 renderer viewport 未同步。前者将状态置入固定工具栏；后者在地图可见时关闭该视图的后台节流，在收到隐藏/最小化事件或移出布局时恢复。此选项会影响同窗口的帧调度，资源代价尚未测量，不宣称没有功耗影响。

## 仍需明确区分的边界

1. 当前页总结仍使用公开 Fetch，最多向模型提供 16000 字符，并固定来源 URL、标题、抓取时间和截断信息；不读取登录态、网站字段或实时动态内容。保存摘要及来源元数据，不默认保存整篇原文。新动线尚未重新做真实服务质量评估。
2. 问答仍是独立的来源绑定问题，多轮上下文不是本次交付。旧问答/对照/判断节点完整保留；进一步收为访问节点下的活动详情尚待精修。原页更多菜单当前提供干净阅读和地图；比较从结果/正文/问答的选源流程进入，个人记录从问答/对照进入。
3. 生产 SearchResult 尚无已验证的图片来源，因此本版节点使用纯文字；没有把原型插图或临时网页截图当作真实网站缩略图。已有两行标题/摘录布局，图片契约及缓存仍待接入。
4. 移除标记与节点原记录进入兼容的 v1 存储；删除不是隐私擦除。撤销栈、地图方向、展开状态和未提交的继续草稿只保留在当前运行期间；查询、问题草稿、答案和判断沿用已有落盘规则。32 个规范节点的既有限额仍含已移除节点，容量策略需后续调整。
5. 地图使用高不透明度底色作为保守回退；跨原生网页的真实背景模糊尚未验收。锁屏使最终完整窗口视检、系统隐藏/恢复事件、全屏、透明边缘点击与读屏人工检查未完成。已观察到锁屏下 `hide()/show()` 改变可见属性但未收到对应事件；没有把这一项列为通过。自动截图不能替代原生视图完整合成或真人体验。
