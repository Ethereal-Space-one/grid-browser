日期：2026-11-04。范围：[ADR 0002](./adr/0002-next-stage-architecture.md) 的第一份工程切片；基于 v0.1.0，不修改版本标签。此记录是本机测试，不是最终内核、安全审计或真人任务验收。

后续更新：窗口/标签内存状态已接续实施，见[第二切片记录](./SMOKE_TABS_2026-11-04.md)。下文单浏览面与测试数量保留为第一切片当时的范围；完整应用退出恢复仍未完成。

## 已实现

- `contracts/browsing.ts` 共用主进程、preload 和界面类型；IPC 主要输入、场景与提供者结果做运行时校验。sandbox preload 只导入类型，不增加第三方运行时 require。
- `application/browsing-session.ts` 不依赖 Electron，管理一个浏览面的权威状态。每个窗口生命周期有独立 owner ID；请求有 ID、取消信号和有效性检查。取消可立即结束本地等待，忽略不合作适配器的晚到结果/错误。
- Search、Fetch 和提取绑定当时的查询、场景和正文句柄。相同 URL 再次获取也产生新正文身份；提取须提供当前 readingId，不能拿旧句柄作用于新正文。
- `providers/deepseek.ts` 收拢服务请求：固定端点、拒绝重定向、15 秒 Search/Fetch 与 20 秒提取超时；响应按实际读取字节限制为 2 MiB，校验 JSON/UTF-8 与内容结构。该限制是当前保守预算，不是服务质量指标；超限明确失败，不冒充完整正文。
- 主进程校验实际 UI webContents、主框架和精确内部文件 URL；远程网页与其他窗口不能因同名或相同页面地址取得调用权限。参数错误避免输出原始诊断/无效 URL 内容。
- 界面依据宿主带版本状态渲染；搜索之外的授权面板、动作和设置变化也推进宿主版本。新请求保留已完成结果，错误不清空结果；重载可从主进程恢复结果/正文。新增“取消请求”，支持键盘并恢复输入焦点。
- 界面重载/渲染进程退出、窗口关闭会取消请求；macOS 关闭后重新打开创建新 owner，不让旧请求补写新窗口。

## 边界与下一阶段

本轮未用个人 key 调用真实 DeepSeek，没有重新评价检索相关性/提取忠实度，没有重跑模型宿主计费测试，也未重新生成或发布安装包。此前 v0.1.0 预览包不自动包含本轮源码；可用 `npm start` 运行当前改动。

仍只有一个浏览面；owner 是窗口生命周期标识，不是完整 TabRegistry。恢复仅覆盖主进程仍存活时的 UI 重载/渲染进程崩溃；整个应用退出后的历史、标签、滚动位置与崩溃恢复尚未实现。取消请求不承诺上游停止处理或计费。

读取/提案/执行确认的完整权限分层、通用人工输入栅栏、发送后写动作的 unknown 与持久执行记录，仍按后续切片实施；本轮未修改固定字段执行器的竞争语义。第二检索源、独立工作进程、正式连接器/fuses 和升级分发也未完成。

下一份工程切片建立窗口/标签归属、每标签导航与结果/阅读位置；真人搜索/场景提取任务继续并行，不用本轮机器测试代替用户判断。

实现依据：[Electron IPC 来源校验](https://www.electronjs.org/docs/latest/tutorial/security)、[Node AbortSignal](https://nodejs.org/api/globals.html#static-method-abortsignalanysignals)。这些资料支持接口与边界做法，不证明整个应用安全。
