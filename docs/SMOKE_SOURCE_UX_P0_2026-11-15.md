# 公开版本 P0：选资料入口与引用语义

## 范围

本轮从公开版本 `f2926104bab753a2a41ba74949c3b06278e9b609` 独立修改旧版 renderer。范围仅含选资料与来源表达，不包含首页续接（P1）或真实接口调用。

- 结果页增加按需「选资料对照」。启用后，所有结果的复选框直接出现在操作行，不再藏在每条「更多」中；普通阅读时隐藏这些复选框。
- 继续沿用主进程持有的最多两份选源，按实际选择顺序显示 A / B。退出模式、Escape、切换阅读位置不会隐式移除已选来源；移除是独立操作。
- 选择模式是界面本地状态。选择资料不发 Search/Fetch/模型请求，也不新增路径节点；只有主动点击「对照这两份」才开始现有对照流程。
- 模式按钮保留 `aria-pressed`、控制范围和说明；每个复选框都有来源名称。模式内 Escape 先关闭焦点所在披露，再退出模式并把焦点交回入口；组合输入期间不拦截 Escape。
- 完整的模型输入正文称作「引用快照」，明确为取得时固定的公开文本，并显示取得时间。「定位快照引文」只定位唯一逐字匹配；重复或缺失只展开快照核对，明确「未定位」，不猜测位置。
- 已释放正文保留引文与取得时间，不承诺完整快照可用；定位入口禁用。个人判断中的固定引文与网站入口也使用不同文案。
- 「打开网站原页」始终表示网站当前内容，不暗中换成快照。既有「定位这段引文」控件、显式第二次点击、一次性定位、绑定检查和拒绝行为不变。
- 搜索短总结仅显示「摘要引用」，不是 Fetch 正文；网页总结仅显示「引用摘录」，不声称保存完整正文快照。

## 可复跑检查

在 `prototypes/electron-m0/`：

```sh
npm ci --ignore-scripts
npm run test:quote:setup
npm run build
npm run test:p0:ux
npm run test:quote:dom
npm test
```

`--ignore-scripts` 仅用于本轮云环境安装编译/DOM测试依赖，不下载 Electron 运行时；需要运行原生 Electron 时按原型 README 的正常安装流程准备运行时。

本轮结果：

- 构建通过。
- 新增 `test:p0:ux`：2 项通过。运行编译后的生产 renderer，选源调用接真实 `BrowsingSession`，提供者使用合成公开资料；验证显式启用、所有行直接选择、点击顺序、两份上限、退出/移除/IME/Escape/披露焦点、切换结果列表、请求边界、快照/摘录/原页文案与取得时间。
- `test:quote:dom`：31 项快照定位检查及 42 项网站定位 DOM 检查通过；既有生产控件/ID-only 原页入口检查通过。重复、重叠、缺失、释放、切换与一次性拒绝等原有安全断言保留，仅更新一个旧文案匹配断言。

## Linux 桌面补验与边界

用实际 Electron 窗口和隔离合成资料点测：进入选择模式 → 不展开「更多」直接勾 A/B → 第三条禁用 → 对照后定位快照 → 打开网站原页 → 后退回到原对照及快照。选满前只有首次 Search；明确进入对照后才出现两个 Fetch 和一次模型调用；随后查看快照、开样例网站及后退没有再发供应商请求。

没有连接用户资料档、使用真实 key 或发出真实供应商调用。未完成原生窄屏/深色/高缩放、读屏、真实网页内容质量或跨机器打包验收；`test:e2e:comparison` 已切到新入口，但本轮未执行该完整脚本。
