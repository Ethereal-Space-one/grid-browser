# 链式地图试用：搜索、提取与继续任务

日期：2026-11-05。本轮自动验证和打包由开发侧完成，真人试用由你进行；这里没有预填任何体验结果。

## 打开这一份预览

本机目录：`prototypes/electron-m0/.local/preview-20261105/`，打开其中的 **Grid Preview.app**；压缩包为 `Grid-Preview-mac-arm64.zip`。这是 macOS Apple Silicon 本地开发预览，版本仍为 0.1.0，构建号 **2026.11.5**。旧预览目录与公开标签保持原样；本轮没有推送或发布。

可直接从当前目录打开应用，不必替换 Applications 中的旧副本。先退出其他 Grid Preview 副本再启动，以免单实例机制把窗口交给旧副本；两份预览使用相同的本机资料位置。若首页提示未配置搜索，在折叠的“搜索服务设置”中保存自己的 DeepSeek key。使用搜索、提取、问答和对照会调用服务；不要将 key 写进反馈或截图。

预览采用本机临时签名，尚无 Developer ID、公证、跨机器安装或自动更新验收。若系统阻止启动，请记录提示，不需关闭系统安全设置。

## 首个任务：搜索并按场景提取正文

选一个你现在确实想弄清楚的问题。可以先完成下列前两步，再按兴趣检查连续浏览。

1. 首页选“学习”或最贴近问题的场景，输入问题并搜索。需要时展开“来源与实际查询”，看场景优化是否改变了你原来的意思。
2. 选择一条结果的“干净正文 B”，再点“按当前场景提取重点”。挑一条重点，对照下方正文；也可打开真实原页。记录提取是否有用、是否遗漏条件、是否加入了原文没有的内容。Fetch 失败时，继续尝试原页入口。
3. 从“问这页”提出一个只围绕该来源的问题，留下一个尚未提交的问题草稿。回到结果，再读第二个来源；展开“地图”，找回第一个来源和问题草稿，再用前进查看选定后续。
4. 如需比较，在结果中将两条来源“选作对照”，点击出现的对照入口。查看适用范围与引文，进入“我的判断”，写自己的结论和待核事项，保存为版本；修改时应形成新版本，旧版仍在。
5. 等“记录”显示“已保存”，使用正常退出，再打开同一份应用。检查当前判断、旧版本、问题草稿和分支。完整正文不随任务保存，阅读页应解释这一点；明确点击“重新获取正文”才取得新版本。

“记录”管理本机任务；“地图”找回当前任务的步骤。任务文件会保留查询、回答、草稿、判断和所选引文，仅在本机且未单独加密。可以在“记录”中删除整条路径；非持久路径不写入任务文件，但各标签仍共用网站登录状态，它不是完整隐私浏览。

## 只需反馈这几件事

- 哪一步让你停下来猜：当时想做什么、点了什么、实际发生什么。
- 哪条提取/回答值得保留，哪条有问题：可只给公开来源链接及相关短句，不需要整段私人任务记录。
- 返回分支或重启后，有没有找不到的位置、草稿或判断；是否因此重复搜索。
- 用惯用浏览器做同一道问题时，哪个更顺手；愿不愿意继续用 Grid，主要原因是什么。

可按“任务 / 场景 / 完成情况 / 卡住步骤 / 内容问题 / 是否愿意再用”简记，不必计时。若愿意做对照，再使用[现有试用表](./developer-trial.template.csv)；真实结果留在本机 `.local/`，不默认提交公开仓库。

自动检查的范围与未验收项见[本轮实现记录](./SMOKE_JOURNEY_2026-11-05.md)。这份试用不预设 Grid 优于惯用浏览器。
