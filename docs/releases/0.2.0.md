# Grid 0.2.0 · 开发者预览

2026-11-05。以 v0.1.0 为基线，合入当前已验证的阅读动线、任务状态与密钥体验修正。此版本仍是 Electron/Chromium 原型，不代表完整浏览器、安全模型或真人收益验收完成。

## 主要变化

- **真实网页优先**：点击搜索结果直接打开原页；网页上方按需总结，右侧展开来源绑定问答。干净阅读保留为可选工具。
- **探索与地图同步**：左侧探索标签与底部浮动地图共同切换。地图支持横竖排列、返回节点、从旧节点继续分支、只移除当前节点并保留后续分支，以及运行期间撤销。节点分别保留两行标题和摘录。
- **恢复工作上下文**：每标签独立管理请求、场景、草稿和路径；迟到响应不覆盖当前任务。正常任务、来源对照与个人判断版本可本机保存，正常退出后恢复；不会自动恢复网站提交或旧授权。
- **保留已有能力**：专业、学习、生活、娱乐、灵感五场景；公开正文提取、两份来源对照、个人判断版本、MCP 授权读取与本地受限填写提案。
- **不再因配置 API key 请求电脑密码**：启动与设置不访问钥匙串。手动输入的 DeepSeek key 仅本次运行有效、不写入磁盘；输入框提交后清空。原有环境变量兼容保留，旧密文不自动读取。

## 使用与升级

macOS Apple Silicon 下载 `Grid-0.2.0-mac-arm64.zip` 并解压。请先用 ⌘Q 完全退出旧版，再打开新的 `Grid Preview.app`。本包为临时签名、未公证的开发者预览，跨机器安装和自动升级尚未验收。

没有 API key 也可直接浏览网址。搜索时，在首页「搜索服务设置」输入 DeepSeek API key 并点「本次启用」；这不是 Mac 登录密码。手动 key 在完全退出后失效，重新打开需再次配置；从已配置环境变量的终端启动仍可直接使用。

已有任务沿用兼容的 v1 本地存储；重开网页需要用户主动操作，不重放 POST、表单填写或授权。仍应保留旧版和重要资料备份，跨版本升级覆盖率尚未充分验证。

源码版本在 `prototypes/electron-m0/package.json` 与 lockfile 中统一为 0.2.0；冻结的 Swift/WebKit Probe 仍保留自身历史版本。本次不会重写 v0.1.0 标签。

## 验证范围

本次版本整理前：77 项本地检查、11 组同窗阅读与地图流程、6 次密钥配置/退出重开检查，以及请求、导航、窗口、理解、对照、判断、存储、MCP 与受限填写的既有回归通过。以真实 Electron UI/IPC 为基础，新增流程使用合成网页和提供者响应。

0.2.0 发布前复验：77 项核心检查、4 项 Swift 检查、11 组同窗阅读流程、6 次密钥启动检查通过。实际 0.2.0 应用包的首页、内置 MCP、两次独立启动的分支/草稿/对照/判断版本恢复通过。46 个包内构建文件与源码构建输出逐字节一致，签名与压缩包校验通过。CI 状态以对应提交的 GitHub Actions 为准，不把运行中状态写为通过。

Developer ID 签名、公证、自动更新、跨机器安装，以及通用网页动作和完整安全模型不在本次完成范围。
