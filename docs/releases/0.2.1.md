# Grid 0.2.1 · 开发者预览

0.2.1 基于已确认的阅读与核对切片，保留 Electron/Chromium 原型定位。版本号不代表已完成正式浏览器、安全模型或广泛用户收益验收。0.2.0 标签和已有附件保持不变。

## 这次变化

- **读网页时保留空间与状态**：上方总结固定高度、内部滚动，引用摘录优先；地图默认紧凑，可切舒展。总结、提问、续接不替用户收起地图；网站输入和滚动保留在存活的原生页面中。外框重排临时抑制滚动锚定，不读取或重放网站字段和滚动坐标。
- **主动选资料和核对来源**：按需进入选资料对照，A/B 直接选择；先看对照结论，再展开证据与来源。固定的公开文本快照、引用摘录和网站当前原页明确区分，不把模型摘要说成已读原文。
- **回到明确的工作位置**：首页继续最近有实质内容的正常探索；从判断引文打开网站后，可在一次性上下文仍有效时返回同一草稿或保存版。返回不重新调用 Fetch/模型、不恢复旧授权。
- **失败仍有出口**：无服务 key 时可打开本次服务设置；公开正文取得失败时可打开该次请求的网站，或普通后退。旧正文不会被标成失败地址的新内容。

## 使用与示例

[当前试用指南](../TRY_GRID_0.2.1.md)分别列出源码启动、无 key 的本地网页例子和使用自带 key 的研究流程。手动 key 仅在本次运行有效，不写入磁盘，不访问钥匙串。任务仍使用兼容的 v1 本机存储，正文全文、网站字段与授权不写入任务记录；请保留重要资料备份。
