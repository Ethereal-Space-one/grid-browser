# Grid Electron M0 · 0.2.0 开发者预览

此目录用于验证“输入 → 搜索结果 → 真实原页 → 按需总结/追问”的流程；干净正文是可选工具。它不是可日用浏览器，也没有完成 M0 的 Agent、安全和用户价值验收。

## 当前同窗阅读版（2026-11-05）

按用户确认的交互模板迁移：标题点击进入原页，上方展开总结，问答与原页同窗；探索标签在左侧，底部小浮钮展开当前地图。地图可横竖、回到旧节点、只移除该点并保留分支、撤销、输入后续接。侧栏和地图名称列表切换的是同一探索，原网页输入与滚动在实例存活时保留。

本版使用现有场景色和浅深色，网站节点分别保留两行标题/摘录。图片来源尚未接入；问题仍独立生成，非连续多轮对话。地图方向/续接草稿/撤销栈只在运行期间保留，移除标记进入已有保存文件。原页更多中有干净阅读和地图，比较/判断仍通过已有选源和理解流程进入。

`npm run test:e2e:reading-flow` 检查真实原生网页/地图与主界面的 11 组交互，使用合成 Search/Fetch/模型；`test:e2e:path-map` 现指向此检查，旧脚本及旧阶段记录留作历史。最新总检查为 77 项，既有请求、标签、导航、理解、对照、判断、MCP/填写、存储已回归。

0.2.0 版本包：`.local/v0.2.0/Grid Preview.app`；压缩包：同目录 `Grid-0.2.0-mac-arm64.zip`。临时签名、未公证，实际指纹见 `build-info.json`。[发布说明](../../docs/releases/0.2.0.md)。锁屏使最终完整窗口视检及系统隐藏恢复未完成，原生玻璃效果、图片、多轮与真人收益不列为通过。完整范围见[本轮记录](../../docs/SMOKE_READING_FLOW_2026-11-05.md)。以下较早阶段的条目按其日期保留，界面状态以此节为准。

`npm run test:e2e:key-storage` 现验证会话密钥：六次独立 Electron 启动覆盖新资料档、旧密文存在、退出重开、两种环境变量及优先级。测试阻断所有 safeStorage 调用，扫描临时资料档不含合成 key；仅使用测试值。[修正记录](../../docs/SMOKE_SESSION_KEY_2026-11-05.md)。

## 运行

需要 Node.js 22.12+。在本目录执行：

```sh
npm ci
npm start
```

若要使用 DeepSeek Search/Fetch，请在启动前于本机终端设置 `DEEPSEEK_API_KEY`。环境变量中的密钥只由 Electron 主进程读取，不进入远程网页；首页也可输入 DeepSeek API key 并点击「本次启用」。输入框随后清空，key 仅在主进程本次运行中使用，不写入磁盘，不访问系统钥匙串，不需要电脑登录密码；完全退出后需重新填写。旧版 provider-key.bin 不读取、不覆盖。不要把密钥写入仓库或截图。未配置时可直接输入 HTTPS 网址，也可访问本机测试页：先在仓库根目录运行 `python3 scripts/serve-fixtures.py`，再输入 `http://127.0.0.1:8765/`。

也兼容已导出的 `DeepSeek_ApiKeyN`；同时存在时优先使用 `DEEPSEEK_API_KEY`。配置后运行 `npm run test:e2e:live`，会在临时浏览器资料档中用真实接口依次验证：搜索与结果展示、Fetch 正文、原页打开、返回结果与查询恢复。它会消耗少量 API 调用，不输出密钥；每个步骤有超时，完整测试最多 90 秒。此项需网络与本机窗口权限，不在普通 CI 中使用真实 key。

测试结束会正常关闭窗口，并把报告保存到被 Git 忽略的 `.local/e2e-live-report.json`。若要测试后继续检查窗口，运行 `npm run test:e2e:live:inspect`；手动试用则运行 `npm start`。

## 当前可验证的行为

- 地址栏区分网址与查询。查询通过 [DeepSeek Search API](https://api-docs.deepseek.com/guides/search/) 返回列表；保留提供者顺序，使用面向 UI 的 `snippet`，不把模型用的 `summary` 当已核对事实。
- 每条结果可打开真实网页（A）或请求 Fetch 正文（B）。B 显示来源与未核对提示；Fetch 失败时仍可打开原页。可从真实原页返回已取得的结果。
- 远程页面使用独立 `WebContentsView`，关闭 Node 集成、启用沙箱和上下文隔离；原型只允许 HTTPS 和本机测试 HTTP，默认拒绝网站权限与弹窗。
- 当前源码已将请求状态移到主进程用例：新查询保留旧结果；返回、切场景和取消会中止旧请求；旧响应不能改写当前状态。正文与原查询/场景绑定，提取校验正文句柄；界面重载可从仍存活的主进程恢复内容，不等于应用退出后的恢复。
- 当前源码支持多窗口/标签；查询、场景、输入草稿和阅读位置各自保留。后退/前进可穿过结果、正文与真实网页；切换仍存活的网页保留原生输入和滚动。结果可在新标签打开。后台请求只更新所属标签，关闭即取消；正常任务的退出恢复已在第 5 步接入；原生网页与授权不自动重放。
- 链式地图的第 1 步已接入底层：返回后新访问保留旧分支；纯用例可按节点恢复场景、草稿与位置。Search/Fetch 从提交到完成使用同一节点，晚响应不能复活取消步骤；等待期间新写的草稿也保留。该步只交付底层，节点选择界面由第 3 步接入，磁盘保存仍未实现。[实测与限制](../../docs/SMOKE_PATH_STATE_2026-11-04.md)。
- 第 2 步已接入宿主受控节点跳转；普通前进/后退和菜单使用同一入口。旧网页访问失效、崩溃或被关闭时保留路径并解释原因；点击“重新打开地址（不重发表单）”才发起新的 GET。Grid 不自动恢复/刷新 POST 步骤，也不恢复旧授权。路径栏和任意节点选择界面在第 3 步接入；运行期间恢复不等于退出后保存。[实测与限制](../../docs/SMOKE_NAVIGATION_2026-11-04.md)。
- 第 3 步已接入一行路径栏及按需展开的分支地图。点节点可恢复已有内容，选择后前进沿该分支继续；当前、后续、其他分支与取消/缺失状态有文字区分。地图独立于内容滚动，与真实网页区域同步，不重新加载网页；Esc 收起回到入口，地图方向键/Home/End 只移动焦点，Enter 返回该步骤。当前正常路径的退出恢复见第 5 步；原始网页状态不自动恢复。[验收记录](../../docs/SMOKE_PATH_MAP_2026-11-04.md)。

`npm run test:e2e:requests` 使用真实 Electron UI/IPC 与合成响应检查请求竞争、键盘取消、旧正文/状态拒绝、调用来源、重载、渲染崩溃及 macOS 关闭重开，无需个人 key。报告位于 `.local/request-e2e-report.json`。[本阶段验证与限制](../../docs/SMOKE_REQUESTS_2026-11-04.md)。UI 校验遵循调用方/主框架/精确内部来源，提供者响应当前最多 2 MiB，超限或格式异常保留旧结果并明确失败。

`⌘/Ctrl+T` 新标签、`⌘/Ctrl+N` 新窗口、`⌘/Ctrl+W` 关闭标签、`⌘/Ctrl+L` 地址栏、`⌘/Ctrl+R` 刷新真实网页。标签栏方向键/Home/End 移动焦点，Enter/Space 选择，Delete 关闭。预览版最多 4 窗口、每窗口 12 标签；每标签最多 32 个记录节点，超过后明确提示只暂存一个当前续页，旧分支不删除。唯一内容记录预算 8 MiB，释放旧正文时保留节点并显示回退入口；这不是进程内存上限。各标签共用登录资料档。

`npm run test:e2e:path-state` 用合成响应检查真实窗口中的分支数据、场景、请求节点/草稿、正文缓存释放和容量提示；纯用例的任意节点跳转由 `npm test` 覆盖。报告位于 `.local/path-state-e2e-report.json`，不调用真实模型。

`npm run test:e2e:tabs` 无需个人 key，验证混合导航/位置、隔离与销毁、后台请求、授权失效、多窗口、键盘及单实例。报告位于 `.local/tabs-e2e-report.json`，实际范围见[标签实测记录](../../docs/SMOKE_TABS_2026-11-04.md)。

`npm run test:e2e:navigation` 使用本地合成网站和真实 UI/IPC/MCP 验证重复 URL、原生位置复用、SPA/锚点/重定向、POST 不重发、视图失效、旧命令拒绝及恢复页键盘/浅深色；不使用个人 key。报告在 `.local/navigation-e2e-report.json`，恢复页截图在 `.local/navigation-post-recovery.png` 和 `.local/navigation-post-recovery-dark.png`。脚本会有意使隔离的网页进程崩溃，测试显式恢复；这不影响个人浏览资料档，也不是崩溃率测量。

地图回归命令为 `npm run test:e2e:path-map`，无需个人 key；报告在 `.local/path-map-e2e-report.json`。包含真实 UI 点击/键盘、分支/场景/阅读位置、原生布局/授权、缩放、内容释放/容量及浅深色/减少动效。组件八状态示例为 `.local/path-map.preview.html`，只供设计检查，不进入生产界面。

## 让现有 AI 工具读取当前页

1. 用 `npm start` 打开 Grid，并进入要读取的真实网页。
2. 点击 **Agent**，选择 **Claude Code / 通用 JSON** 或 **Codex TOML**，再点击 **复制 MCP 配置**，将配置加入对应客户端；源码启动需有 Node.js 22.12+；打包预览使用内置运行时。通过 npm 启动时会复制实际 Node 可执行文件的绝对路径，减少 GUI 客户端找不到 nvm 中 Node 的问题。配置不包含模型 key，MCP 读取本身不需要 key。
3. 在客户端调用 `grid_connection_status`，Grid 会显示该客户端的连接请求；确认页面后点击 **允许读取当前页**。
4. 客户端调用 `grid_page_snapshot` 读取页面语义摘要；在 Grid 中可随时撤销，也可导出 JSON 读取回执。导航后需要重新授权。

授权最多十分钟，仅针对最近激活的 Grid 窗口中当前文档。切换标签/窗口、导航、隐藏或最小化会撤销，切回不自动恢复；关闭无关后台标签不撤销当前页授权。外部编程工具取得焦点本身不撤销仍可见的 Grid 页授权。客户端名称为自报，页面数据会返回给该客户端。摘要排除已识别的输入及可编辑子树，但不保证过滤站点放在普通文本中的敏感信息。只覆盖主框架，不提供通用写动作或敏感操作授权。

`npm run test:e2e:mcp` 运行无需模型 key 的真实 Electron/MCP 链路检查。2026-11-03 已另外通过 Codex CLI 和 Claude Code 的真实模型调用，真人首次接入体验仍待测量。[SDK 实测](../../docs/SMOKE_MCP_2026-11-02.md) · [编程工具实测与配置步骤](../../docs/SMOKE_HOSTS_2026-11-03.md) · [ADR](../../docs/adr/0001-local-read-only-mcp.md)

真实宿主测试需要已经安装并登录对应 CLI，会消耗该工具的模型用量。运行 `npm run test:e2e:hosts`，或分别运行 `npm run test:e2e:hosts -- --host=codex` / `npm run test:e2e:hosts -- --host=claude`。它使用独立临时资料档和本地合成网页，由测试脚本在首次拒绝后自动点击授权；不修改全局 MCP 配置，不使用你的真实网页或 DeepSeek key。每个宿主最多等待 90 秒；结果存入被 Git 忽略的 `.local/hosts-e2e-report.json`。失败也返回非零退出码，报告不包含模型原始输出、网页正文或凭据。仅供 macOS 开发实测，不纳入普通 CI。

## 按需短总结与问这页（4A）

搜索结果先出现，点击“生成短总结”才会发送前 10 条结果的摘要给 DeepSeek；不改变提供者顺序，也不声称已读原文。失败或停止时结果仍可打开。

在干净正文点击“问这页”，进入独立提问页面；提交会把这版公开正文最多前 16000 字符和本次问题发送给模型，每次独立作答，不附加前次回答。原页入口使用公开 Fetch 获取正文，明确不读取登录态/动态页面和编辑字段。进入提问页本身不调用接口。回答包含可点回到该版正文的逐字依据、来源版本和生成时间；资料不足明确说明，引用不匹配或输出截断会拒绝显示为成功回答。引文匹配不证明结论正确。

问题、回答与未提交草稿参与当前路径，正常路径可随任务文件恢复；返回已有步骤不再调用服务。“返回来源位置”保留先前正文与阅读位置；原始正文仍可打开。第 5 步已接任务保存；正文全文不落盘，非持久路径仍不恢复。

`npm run test:e2e:understanding` 用隔离资料档、合成 Search/Fetch/Model 和生产 UI/IPC 验证上述行为；不使用个人 key，不调用外网模型。9 组报告在 `.local/understanding-e2e-report.json`，实际截图及八状态设计示例也只写入 `.local`。当前构建与 46 项本地检查通过；[实测范围与限制](../../docs/SMOKE_UNDERSTANDING_2026-11-04.md)。既有 `test:e2e:live` 仍只验证原来的搜索/Fetch 流程，不能当作本轮总结/问答真实接口验收。

## 两份来源对照（4B）

在当前标签的搜索结果、Fetch 正文或带正文的问答页点“选作对照”。选择不调用服务，不新增路径节点；先选一份继续阅读，选满两份才出现临时“对照这两份”入口。一次只对照两份，同一地址不能用不同锚点重复选择；移除后可换一份或选择更新的正文版本。

点击后进入独立对照页，固定所选来源、版本、查询与场景。已选正文版本直接使用，尚未取得的来源才获取公开 Fetch 正文；每份最多向 DeepSeek 模型发送前 16000 个 Unicode 字符，不读取登录态、编辑字段或其他标签。显示一致、分歧、适用范围不同与资料不足，均为待核对的 AI 分析。左右依据分别逐字校验，可定位到对应版本原文，再回到刚才的对照项。

抓取失败保留成功来源，明确补取只请求缺失正文；模型失败保留两份版本。停止会取消未完成请求，返回旧对照不重新调用服务。正文/回答缓存释放后保留来源与原版时间，点击“重新获取两份正文并对照”才取得新版本并创建新步骤，不冒充原来的结论或网页快照。对照正文仍只存在内存；正常路径保存结论、引文与来源元信息，重启后正文需明确补取。

`npm run test:e2e:comparison` 用隔离资料档、合成服务/HTTPS 原页与生产 UI/IPC 验证以上流程，并检查本机 MCP 授权和布局。11 组报告位于 `.local/comparison-e2e-report.json`，截图及八状态示例也写入 `.local`；不需要个人 key，不调用外网模型。[实测与边界](../../docs/SMOKE_COMPARISON_2026-11-05.md)。此为 4B 当时的 55 项检查记录；当前检查总数见下方 4C。真实内容质量及真人收益仍需另验。

## 我的判断（4C）

从完成的问答/对照点击“记录我的判断”后进入独立页面。结论和待核事项由你填写；原文引文按需展开、逐条选择，AI 建议单独折叠且不会自动变成个人文字。草稿随输入保留在当前分支；“保存为新版本”新增只读节点，修改从新草稿开始，旧版本不覆盖。引用固定到当时的正文 ID/时间与逐字片段，返回参考位置不重新调用模型。

4C 最初仅保留本次运行；当前第 5 步已接正常路径的本机保存与退出恢复，非持久路径仍不落盘。 个人文字不发送给模型。沿用 32 个路径记录与 8 MiB 文本预算，优先保留个人判断；无法容纳新版本时保留现有草稿并明确报错。结论最多 4000 字符、待核事项 2000 字符，引用仅可选 Host 派生的句柄，不能提交任意引文地址。

## 本地路径与恢复（第 5 步）

正常路径自动把查询、必要结果、回答、草稿和判断保存在本机；「路径」按钮显示提交状态，展开后可立即保存、恢复最近路径、确认删除或新建非持久路径。原始正文全文、网站字段和授权不进入任务文件；重启先恢复任务位置，原页和缺失正文等你明确点击后再获取，不重发网站操作。

任务文件位于应用资料目录的 `tasks-v1`，未单独加密；最多 48 条路径、单条 2 MiB、总任务载荷 24 MiB。不静默删除旧判断，容量或写入失败会明确提示并保留当前标签。正常退出最多等待 5 秒检查保存；异常退出只恢复最近提交。未知或损坏的保存空间保留原件并停止覆盖，仍可继续浏览。

非持久路径不进入任务文件，关闭后不能从任务库恢复；各标签仍共用网站登录状态，因此不是完整隐私浏览。删除清理任务的旧代及临时文件，不清网站资料或另行导出的回执。

`npm run test:e2e:storage` 用四个独立 Electron 进程验证两窗口/多标签、分支、草稿、判断、关闭路径的恢复、删除/非持久任务以及未知格式保护；第 5 步当时的 `npm test` 为 74 项（第 6 步增至 75 项）。[实测记录与限制](../../docs/SMOKE_STORAGE_2026-11-05.md)。本机检查不等于跨平台安装、真实断电或真人收益验收。
