# Grid 同窗阅读交互原型

复核「搜索 → 真实网页为默认主区 → 上方总结 → 侧面追问 → 链式地图返回」及按钮层级。设计与完整功能去向见 [设计记录](../../docs/READING_FLOW_DESIGN_2026-11-05.md)。

**这是离线合成原型，未接入正式 Electron 产品。** 页面、结果、回答和对照均为示例，不联网，不读取 key。记录仅在本次打开期间保留。Agent 控件只演示状态，不填写网页。生产版已有功能不以此原型为实现来源。

从仓库根目录运行：

```sh
node prototypes/reading-flow/build.mjs
open prototypes/reading-flow/index.html
```

预览直接展示两条合成探索，方便比较切换入口。**一枚探索标签对应一张地图，网页是链内节点**：左上导航直接选标签；底部地图标题旁的箭头展开切换列表，显示名称、上次停留页和节点数；收起后也可点浮钮旁的箭头切换。网页与地图共同回到该链上次位置，原型内的页内输入、阅读位置、问题/续接草稿与地图方向分别保留；同名标签身份独立。切换本身不生成新节点，Esc 取消并回到原来的入口与展开状态。左侧「当前链的网页」可在同链访问间切换。

「新建探索」另开一条链；「从此处继续」在当前链保留旧分支并新开分支。通过「演示状态 → 重新开始」回到首页，选择场景后搜索、点击结果标题；「查看多标签示例」恢复两链演示。阅读时点「总结这页」，完成后点「继续问这页」。底部的「地图 · 当前名称」展开贴底毛玻璃区域，默认横向，可切纵向；图内滚动，地图随窗口保持底部位置。「移除此节点」保留后续分支和当前网页，支持撤销；撤销也保留之后新增的分支。收起或 Esc 回到浮钮。

网页更多中保留干净阅读、比较来源和我的记录；本地记录、设置与 Agent 在导航底部。顶端「演示状态」是原型检验工具，不属于产品。地图移除只整理访问关系，不清除网站状态、关联活动或整条任务。原型撤销仅在内存；正式持久化和真实网页上的可信浮层尚未接入。

网站节点缩为 164px 宽，分别保留两行标题和两行内容摘录；长文字省略，完整文字保留在悬停/焦点提示及可访问名称/描述中。左侧探索标签与当前链网页保留两行标题，搜索结果内容也预留两行。摘录取已有文章导语，不额外生成。第一篇示例的插图缩为顶行 44×26px 小预览，另外两篇保持纯文字，不挤占标题和摘录宽度。图片点击同样返回该页；加载失败后移除图片，文字和导航可用。[图片来源](./assets/README.md)为本地合成文章，构建时嵌入，不访问外网。

毛玻璃只用于底部地图区域，节点采用更实的底色保证阅读。减少透明度、增强对比或浏览器不支持模糊时回退实色；展开/收起地图不重建网页，也不改变网页内容尺寸。

自动检查（复用已有 Electron，无新增依赖）：

```sh
node prototypes/reading-flow/build.mjs
prototypes/electron-m0/node_modules/.bin/electron prototypes/reading-flow/check.cjs
```

测试只打开本地页面并使用临时资料目录。报告/截图在 `.local/`。测试不调用 `npm start`，也不访问真实浏览器资料档。`build.mjs` 将共享 `tokens.css` 限定到原型根节点，生成 `index.html`；传入一个输出路径时，额外输出同源的内联预览片段，避免两份交互逻辑分叉。

内联预览兼容：预览容器额外加载的 Floating UI / Lucide 辅助脚本失败时，可以触发 `Visualization script could not be loaded`。`inline-compat.js` 只为已知版本的这三个可选脚本设置失败回退：文字图标继续可用，完整标题提示改用本地实现。其他脚本及交互错误仍报告，不全局屏蔽错误。此修复仅作用于预览，不修改正式浏览器。

嵌入检查使用生成片段与宿主提供的预览模板，在隔离 iframe 中主动阻断所有外部请求，验证地图切换、总结、焦点提示，以及其他错误仍可报告。传入当前环境的片段和 Visualize 技能目录：

```sh
prototypes/electron-m0/node_modules/.bin/electron prototypes/reading-flow/check-inline.cjs <fragment.html> <visualize-skill-directory>
```

检查会短暂显示测试窗口以产生真实焦点事件，完成后关闭；结果写入 `.local/inline-report.json`，截图为 `.local/inline-preview.png`。本机复验不等同于确认用户当前聊天容器已恢复。

预览的窄窗布局是检查缩放与布局韧性，不代表 Grid 将发布移动端浏览器。
